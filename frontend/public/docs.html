2. Tạo tài khoản và lấy khóa API (gw_)

  1. Vào trang Đăng ký tạo tài khoản miễn phí (hoặc Đăng nhập nếu đã có).
  2. Trong Console, bấm + Tạo khóa mới, đặt tên gợi nhớ (ví dụ: Roo Code máy bàn, Cursor laptop) rồi bấm Tạo khóa.
  3. Bấm Sao chép khóa. Bạn có thể tạo nhiều khóa khác nhau — tất cả các khóa dùng chung một ví USD của tài khoản, và có nút Sao chép ngay bên cạnh khóa trong bảng để lấy lại bất kỳ lúc nào.

4. Cấu hình chi tiết theo từng công cụ

Chọn công cụ bạn đang dùng để xem hướng dẫn và mẫu cấu hình sẵn.

  1. Mở cài đặt (biểu tượng bánh răng) trong Roo Code / Cline / Kilo Code.
  2. Mục API Provider: chọn OpenAI Compatible.
  3. Mục Base URL: nhập https://api.tiencoder.tech/v1.
  4. Mục API Key: dán khóa gw_... từ Console.
  5. Mục Model: nhập chính xác 1 ID ở mục 3 (ví dụ gemini-3.8-flash). Bấm Done / Save là dùng ngay!
  1. Mở Cursor Settings → Models.
  2. Cuộn xuống mục OpenAI API Key: dán khóa gw_... của bạn.
  3. Bật công tắc Override OpenAI Base URL và nhập: https://api.tiencoder.tech/v1.
  4. Bấm + Add Model, nhập chính xác ID model ở mục 3 (ví dụ gemini-4-hydrogen-high) rồi bật model đó lên.

Tạo hoặc sửa file cấu hình OpenCode tại ~/.config/opencode/opencode.json (Windows: C:\Users\<TenUser>\.config\opencode\opencode.json, hoặc đặt opencode.json ngay trong thư mục dự án):

~/.config/opencode/opencode.json
  1. Thay gw_KEY_CUA_BAN bằng khóa gw_... trên Console (hoặc dùng "{env:TIENCODER_API_KEY}" nếu bạn lưu key qua biến môi trường).
  2. Chạy lệnh opencode trong terminal, sau đó gõ /models và chọn model thuộc nhóm TienCoder API.
  3. Có thể thêm bất kỳ ID model nào ở mục 3 vào khối "models" trong opencode.json. Test nhanh 1 dòng: opencode run --model tiencoder/gemini-3.8-flash "Xin chào!"

Mở file ~/.codex/config.toml (Windows: C:\Users\<TenUser>\.codex\config.toml) và thêm cấu hình sau:

~/.codex/config.toml

5. Cơ chế ví chung, tính phí & theo dõi trực tiếp

  • ✓ Ví chung tài khoản: Mọi khóa gw_ bạn tạo đều dùng chung một số dư USD của tài khoản chính — khóa nào gửi request thì trừ vào ví chung.
  • ✓ Tính phí theo token thật: Hệ thống giữ chỗ trước khi gọi model, sau khi phản hồi xong sẽ chốt trừ đúng theo số token đầu vào & đầu ra thực tế (đơn vị USD, chính xác tới $0.000001).
  • ✓ Cập nhật trực tiếp (Live 3s): Mở Console hoặc Tra cứu /usage để xem từng request nhảy lên theo thời gian thực (Giờ Việt Nam UTC+7).
  • ✓ Không lưu nội dung prompt: Gateway chỉ lưu thời gian, model, mã HTTP, số token và chi phí để đối soát.

6. Xử lý các lỗi thường gặp

API key not valid. Please pass a valid API key.

Bạn đang chọn nhầm Provider là Google Gemini trong IDE/app. Hãy đổi Provider sang OpenAI Compatible và đặt Base URL là https://api.tiencoder.tech/v1.

404 model_not_found

Tên model gửi lên chưa khớp với danh sách đang mở. Hãy sao chép chính xác ID model ở Mục 3 (lưu ý không thêm tiền tố ag/).

401 invalid_key / key_disabled / key_expired

Khóa bị thiếu/sai ký tự, đã bị vô hiệu hóa hoặc đã hết hạn. Vào Console kiểm tra trạng thái khóa và bấm nút Sao chép để dán lại.

429 quota_exceeded

Số dư còn lại trong ví tài khoản không đủ mức giữ chỗ cho lượt gọi này. Hãy kiểm tra số dư trên Console, thử model tiết kiệm hơn (như gemini-3.8-flash) hoặc liên hệ quản trị viên để nạp thêm ví.

403 model_forbidden

Khóa này đang bị giới hạn danh sách model được phép gọi. Vào Console → bấm Sửa trên khóa → chọn Tất cả model được cấu hình.
